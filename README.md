# 🎬 Chandan Kumar Kisku – Personal Portfolio

A modern, Netflix-inspired personal portfolio website designed to showcase my professional profile, internship experience, technical skills, and projects through an interactive streaming-platform-style interface.

## 🌟 Features

- **Netflix-Inspired UI:** Dark theme with Netflix-style red accents.
- **Animated Intro Screen:** Cinematic logo animation when the website loads.
- **Profile Selection:** Choose between Recruiter and Me profiles.
- **Hero Section:** Professional introduction and career highlights.
- **Internship Experience:** Showcases internship experience at Bharat Coking Coal Limited (BCCL).
- **Projects Showcase:** Highlights AI and technology projects.
- **Technical Skills:** Displays programming languages, AI/ML technologies, and development tools.
- **About Section:** Brief professional introduction.
- **Contact Section:** Quick access to GitHub, LinkedIn, and email.
- **Responsive Design:** Adapts to desktop, tablet, and mobile screens.
- **Smooth Animations:** Hover effects, transitions, and smooth scrolling.
